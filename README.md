## Objectifs du projet

Realiser un jeu video en 2D pixel-art avec pygame_ce et pygame_gui qui remplis le [cahier de charge](https://quentin.lurkin.xyz/courses/python2ba/project26/)

## Defis du projet

 - Essyer de cree un system de vue `isometric` pour la camera
 - Faire sois-meme les sprite du jeu en `pixel art` ( donc en 2.5D )
 - Utiliser le paradigme de l'`ECS` au lieu de la POO classique
